# 更新日志

## 1.0.0 — 2026-10-27

第一个正式版。**Cosmolayor** 是一个给 OBS 用的直播叠加层：一个浏览器源、一个本地服务、零第三方依赖。

### 四个组件

- **角标**：三角徽章（封面 / 歌名 / 进度），左下或左上镜像布局，斜边上有实时频谱
- **条幅**：一行到底 —— 封面 / 歌名 / 歌手 / 进度条 / 时长，超长文字来回滚动
- **播放卡片**：大封面 + 进度 + 底部 30px 小频谱，0.75×～1.5× 等比缩放
- **频谱**：64 段真实频谱（WASAPI 回环 + 页面自写 FFT），位置 / 大小 / 帧率都能调

### 数据全本地

| 数据 | 来源 |
|---|---|
| 歌名 / 歌手 / 播放状态 | Windows SMTC（PowerShell 5.1 + WinRT） |
| 封面 | 自写 C# 读 SMTC 缩略图（`csc.exe` 现场编译） |
| 进度 | 自写解码 `cloudmusic.elog`（网易云真实 position / seek） |
| 频谱 | ctypes 直调 WASAPI 进程回环（只抓网易云，可切整机混音） |

不联网、不上传、不需要登录。

### 控制面板

- 每个组件都有自己的 ▾：开关 / 位置 / 透明度 / 大小 / 重置
- 8 套配色，其中 4 套霓虹撞色的强调色走**渐变**
- **跟随封面取色**：从封面抓主色生成配色，可再叠一层渐变
- 整体圆角 0～44、封面旋转（圆形限定）、封面形状切换
- 实时预览里直接拖动组件，松手自动保存

### 运行方式

- 双击 `Cosmolayor.exe`：弹黑窗口（日志在里面）→ 自动打开控制面板，关窗口即停
  （exe 被拦时改双击 `Cosmolayor.cmd`；发布包自带 Python，不用装）
- 或 `start.cmd` / `python -u server.py`
- 只要 Python 3.9+（用到的都是标准库）；OBS 里填 `http://127.0.0.1:8765/index.html`

### 兼容性

- Windows 10 20348+ / Windows 11（进程回环）；更老的系统会退回整机混音
- 网易云音乐：元数据、封面、真实进度全部支持；别的播放器能拿元数据，进度看 SMTC 给不给

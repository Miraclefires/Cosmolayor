# 测试说明（v1.0.0 beta）

谢谢你帮忙测。这个包**解压就能用，不用装 Python**。

## 先做这三步

1. 把 `Cosmolayor-1.0.0` 文件夹**解压到没有中文、没有空格的路径**（比如 `D:\Cosmolayor`）
   —— 中文路径一般没事，但出问题时先排除这一项
2. 双击 **`Cosmolayor.exe`**：会弹一个黑窗口（日志），2 秒后自动打开控制面板
   **第一次会被 SmartScreen 拦一下**：显示「Windows 已保护你的电脑 / 发布者：未知」，
   因为 exe 还没做代码签名（这件事排在 1.0 之后，见 HANDOFF）。点 **「仍要运行」** 即可；
   有的系统版本要先点「更多信息」再点「仍要运行」。不放心就双击旁边的 `Cosmolayor.cmd`，功能一样、也没有这个提示。
3. 控制面板里能看到「正在播放」有歌名，就说明链路通了


OBS 里：来源 → 加号 → **浏览器** → 宽 `1920` 高 `1080` → 地址 `http://127.0.0.1:8765/index.html` → 勾「源不可见时关闭」。

## 要测什么（能测几项算几项）

### A. 基础

- [ ] 双击后能起来，控制面板能打开
- [ ] 放一首歌，「正在播放」出现歌名 / 歌手 / 封面
- [ ] 进度条会走，暂停时冻住，拖进度条 1 秒内跟上
- [ ] 切歌：封面、时长、角标都跟着换

### B. 四个组件（面板「组件」卡）

- [ ] 角标：左下 / 左上都能放，斜边频谱跟着音乐跳
- [ ] 条幅：一行显示 封面 / 歌名 / 歌手 / 进度 / 时长；长歌名会来回滚
- [ ] 播放卡片：大封面 + 进度 + 底部小频谱；滑杆能 0.75×～1.5× 缩放
- [ ] 频谱：64 段跟着音乐跳；能拖位置、能缩放

### C. 面板

- [ ] 每个组件右边的 `▾` 里：开关 / 位置 / 透明度 / 大小 / 重置 都能用
- [ ] 8 套配色点得动；「跟随封面」打开后颜色跟着封面变
- [ ] 画布上直接拖动组件，松手后刷新页面位置还在

### D. OBS 里

- [ ] 1920×1080 下位置正确、背景透明（没有白底）
- [ ] 缩到 1280×720 不难看

### E. 异常场景（最有用）

- [ ] 先开叠加层、后开网易云 → 放歌后能不能自己接上
- [ ] 关掉网易云 → 画面是空着还是卡住
- [ ] 电脑同时放浏览器视频（B 站 / YouTube）→ 频谱**不应该**跟着浏览器跳（默认只抓网易云）
- [ ] 换一个播放器（Spotify / QQ 音乐 / foobar2000）→ 能显示什么、缺什么

## 怎么反馈

尽量按这个格式，一条 bug 一段：

```
【现象】角标在 1280×720 下被切掉一截
【我的环境】Win11 26200 / 网易云 3.x / OBS 31.0.2 / 缩放 125%
【怎么复现】1. 打开面板 2. 把角标拖到左上 3. OBS 缩放
【期望】……
【截图】……
【诊断】cosmolayor-diag-20261027-2130.txt
```

**诊断包怎么拿**：控制面板最下面「诊断」卡 → 点 **「导出诊断」** 按钮，会下载一个 txt。
里面有系统版本、Python 版本、当前状态、数据桥/音频状态、网易云进程数 —— 没有歌单、没有账号、没有路径以外的个人信息。

有黑窗口的话，把窗口里最后几十行也一起截图发来（异常信息在那里）。

## 已知限制（不用报）

| 现象 | 原因 |
|---|---|
| Win10 19045 及以下：频谱是「模拟」 | 进程回环要 20348+，老系统只能抓整机混音 |
| Spotify / QQ 音乐：进度不动 | 只有网易云能从本地日志拿到真实进度，其它播放器看它给不给 SMTC |
| 卡片里的作者是省略号、不滚动 | 这是设计（卡片空间小） |
| 面板预览里是假背景 | 预览加了底衬，OBS 里是透明的 |
| 关掉黑窗口后 OBS 画面冻住 | 服务停了，页面保留最后一帧 |

# 直播角标 · Now Playing Badge

左下角的音乐播放角标：三角楔形 + 圆形封面 + 斜边频谱 + 胶囊进度条。

---

```
├── build_badge.py        生成器（参数化，改配色/圆角都靠它）

```

## 在 OBS 里用

1. 添加来源 → **浏览器**
2. 勾选「本地文件」，选 `badges/magenta.html`
3. 尺寸：**564 × 254**（画布含 32px 内边距）
4. 位置：
   - 想要"留边"效果 → 放 `(0, 0)` 到左下角，形状自带 32px 呼吸空间
   - 想要"贴死角落" → 放 `(-32, -32)`，形状会顶到画面边缘
5. 背景自动透明，无需抠像

> 1080p 下如果觉得小，整体放大到 **733 × 330**（1.3 倍）会更舒服。

## 重新生成

```bash
python build_badge.py <直角圆角> <输出名> <配色>
```

例：

```bash
python build_badge.py 30 magenta magenta    # 品红，30px 圆角
python build_badge.py 20 acid    acid       # 荧光绿，20px 圆角
python build_badge.py 0  sharp   cyan       # 完全直角
```

配色可选：`cinnabar` / `cyan` / `magenta` / `acid`

生成后输出到当前目录，把 HTML 挪进 `badges/` 即可。

## 关键参数

| 项目 | 值 | 位置 |
|---|---|---|
| 画布 | 564 × 254（500×190 + 32 内边距） | 文件顶部 `PAD` |

| 胶囊范围 | d=12 → 480 | `d0, d1` |

## 设计决策记录（为什么是现在这样）

- **只圆直角，不圆尖端** —— 尖端保持方向感，一个软角让形状有"性格"
- **频谱在形状外侧** —— 模拟声音从角标溢出
- **频谱带黑色底衬** —— 否则在同色相背景（如紫红画面）上会消失
- **环境光带**（斜边内侧 52px 柔光）—— 否则暗场景里楔形会糊成一片
- **胶囊 3px** —— 6px 时与频谱形成"双亮带"，太粗；2px 时圆头特征消失
- **进度条用圆头线** —— `stroke-linecap="round"` 天然生成胶囊，无接缝

## 已知限制

1. **字体依赖 Windows**
   用的是 `Segoe UI` / `微软雅黑`。Mac/Linux 上会回退，字宽变化可能导致文字贴边。跨平台需内嵌字体或加 15% 余量。

2. **贴死角落时圆角会被切**
   直角圆角是为"留边显示"设计的，贴边时画面边缘会把圆角裁掉——这是预期行为。

3. **时间码是静态的**
   目前写死在 `timeline(elapsed, total)` 里。接实时数据需要改这个函数的数据来源。

4. **频谱是固定随机种子**
   `mulberry32(20261025)`，每次渲染完全一致。想要真正的音频响应需要重写。

5. **封面是渐变占位**
   朱砂→紫的渐变 + 音符符号，不是真实专辑封面。
